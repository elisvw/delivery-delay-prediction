# Predição de Atrasos em Entregas 🚚

## Contexto e Problema de Negócio
A empresa fictícia EntregaCerta enfrenta dificuldades em cumprir os prazos de entrega prometidos aos clientes. Os atrasos podem comprometer a satisfação dos consumidores e aumentar os custos operacionais. Por isso, a empresa busca identificar os fatores associados aos atrasos e prever quais pedidos apresentam maior risco de não serem entregues no prazo.

## Objetivos do Projeto
- Analisar os fatores associados aos atrasos nas entregas, desenvolvendo e comparando modelos de Machine Learning para classificar os pedidos quanto à ocorrência de atrasos.
- Desenvolver um dashboard no Power BI para apoiar a tomada de decisões e contribuir para a melhoria do planejamento logístico.

## Base de Dados
A base de dados é sintética, gerada pelo ChatGPT, e composta por aproximadamente 30 mil registros de pedidos de uma empresa fictícia de comércio eletrônico. Ela possui informações relacionadas às entregas de produtos para diferentes regiões do Brasil, incluindo:
- Características dos pedidos;
- Categorias de produtos;
- Transportadoras e modalidades de envio;
- Distâncias percorridas;
- Prazos prometidos;
- Disponibilidade de estoque;
- Condições operacionais.
